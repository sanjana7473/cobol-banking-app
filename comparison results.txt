Verdict
-------
  Both environments produce IDENTICAL functional results across all 28 runs
  (14 local + 14 Oracle Cloud), so functional fidelity is equivalent.

  Oracle Cloud is on average ~18.95s SLOWER per pipeline run than local
  (40.91s vs 59.86s mean total). The gap is almost entirely compile time
  (6.05s local vs 21.10s Oracle) — the Oracle Always Free instance's CPU is
  noticeably slower than the local host for IKFCBL00 compilation. The run
  (BANKRUN) step also differs (3.89s vs 8.06s).

Setup Complexity
----------------
  Both environments use the same setup_tk5.sh + pure-ftpd + tk5-ftp-watcher.sh
  path. The only difference is the transport target:
    Env A: localhost
    Env B: SSH to the Oracle VM (150.136.240.50)
